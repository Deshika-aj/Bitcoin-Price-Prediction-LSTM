# Bitcoin Price Prediction Using LSTM

## Project Overview
This project uses a Long Short-Term Memory (LSTM) neural network to analyze historical Bitcoin closing prices and generate experimental price forecasts.

## Technologies Used
- Python
- Pandas and NumPy
- TensorFlow / Keras
- Matplotlib
- Google Colab

## Workflow
1. Load the historical Bitcoin price dataset.
2. Clean and preprocess the data.
3. Normalize closing prices using MinMaxScaler.
4. Prepare training and testing sequences.
5. Train the LSTM model.
6. Evaluate predictions using MAE and RMSE.
7. Visualize actual and predicted closing prices.
8. Generate an experimental 30-day forecast.

## Evaluation
- MAE: 454.47
- RMSE: 585.69

## Disclaimer
The forecasts are experimental model outputs and are not guaranteed to represent actual future Bitcoin prices. This project is for educational purposes only.

## How to Run
Open the `.ipynb` notebook in Google Colab and run the cells in order. Upload the required dataset when prompted.
